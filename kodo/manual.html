KŌDŌ 操作説明書 v0.18

目的を決める → 行動を記録する → よりよい方法を比べる。時間とお金の投資から、得られる利益まで考えるための操作ガイドです。

まずはここから

初めてなら、最初からすべての機能を覚える必要はありません。「行動を分析」で1件登録するところから始めましょう。

01　基本の考え方

KŌDŌには、3つの階層があります。

目的何を達成したいか
例：朝の準備を終える
方法どのやり方で達成するか
例：今のやり方・改善案
行動実際にする作業
例：温める・片付ける

最初に目的を選び、その下に方法、その方法の中に行動を登録します。メニューはスマートフォンではアイコンだけになる場合があります。アイコンの説明はアプリの各画面でも確認できます。

最初は「行動を分析」だけで大丈夫。記録を増やしてから時間、費用、利益を比較します。

02　最初の1件を登録する

例：「朝の準備」を登録する

  1. Safariで KŌDŌ を開き、「行動を分析」（つながった丸のアイコン）を選びます。
  2. 「目的を追加」を押し、名前に「朝の準備」、目指す状態に「時間どおり出発する」と入力して保存します。
  3. 「方法を追加」を押し、「今のやり方」を作ります。
  4. 「音声・文章で記録」を押し、普段の行動を入力します。
  5. 「端末内で候補を抽出」を押します。候補の名前と種類を確認し、必要なものをチェックして「選んだ行動を登録」を押します。
練習文

朝、お湯を沸かす。待っている間に食器を片付ける。飲み物を用意する。カップを洗う。

一度で完璧にしなくても構いません。後から各行動の名前や所要時間を編集できます。

03　音声入力とAIによる整理

  1. 「行動を分析」→「音声・文章で記録」を開きます。
  2. iPhoneでは文章入力欄をタップし、キーボードのマイクから日本語で話します。画面内マイクはブラウザによって利用できない場合があります。
  3. 短い文章なら「端末内で候補を抽出」。ログインしている場合は「AIで短く整理して抽出」で話し言葉を短い行動名へ整理できます。
  4. 抽出された候補を確認・編集し、最後に登録します。
入力例

毎朝ゴミをまとめて、ゴミステーションに持って行く。火曜日はまとめて回収場所へ出す。

候補例

ゴミを袋にまとめる／ゴミステーションに運ぶ／火曜日に回収場所へ出す

AIは時間や因果関係を勝手に確定しません。提案された項目が実際に必要か確認してください。AIが使えないときでも端末内の候補抽出は利用できます。

04　行動を編集し、時間・費用を入れる

「行動を分析」→目的を選ぶ→方法を選ぶ→行動のカード→「編集」の順です。

行動名「食器を片付ける」など具体的な短い名前
種類中心行動／準備・補助／後処理・管理
1回の時間実測した時間（分）。不明なら空欄
回数／週1週間に何回行うか
1回の費用毎回必要な円額
必須の行動省くと安全・品質・目的達成に問題がある場合にチェック
片付け3分 × 週5回 ＝ 毎週15分

「未測定」と「0分」は別です。分からない時間をゼロとして入力しないでください。

05　今の方法と改善案を比較する

  1. 「行動を分析」で現在の方法の行動・時間を登録します。
  2. 「方法を複製」で新しい方法を作ります。
  3. 削減できる行動だけでなく、新たに増える作業も編集します。
  4. 方法の編集で初回の準備時間・初期費用・毎週の追加管理時間を登録します。
  5. 「方法を比較」で評価期間（例：12週間）を選びます。
12週間の比較例

今の方法：30分／週 × 12週 ＝ 360分

改善案：初期60分 ＋ 20分／週 × 12週 ＝ 300分

差：60分短縮（実際の効果は実測して確認）

行動数が増えても、準備・片付け・管理を含む総時間が減るなら改善です。

06　待ち時間に別の行動を重ねる

電子レンジや乾燥など、人が短縮できない時間に、安全に別の仕事を進める場合の試算機能です。

  1. 時計アイコンの「待ち時間を活かす」を開きます。
  2. 「機械の運転・待機」と「その間にする、もともと必要だった作業」を入力します。
  3. 準備・待ち時間・別作業・後処理・切替負担・週の回数を入力します。
  4. 安全／待ち時間の終了前に着手できる／もともと必要な作業の3項目を確認します。
  5. 「計算して保存」で従来と並行後の経過時間を比較します。
電子レンジの例

温め3分＋後で行う片付け2分 → 順番に行うと5分、並行できれば完了まで3分。

経過時間は2分短縮。人が行う片付け2分は減っていません。

安全確認が先です。監視が必要な機械や火気などは無理に並行しないでください。

07　時間とお金の投資・利益を分析する

  1. 星のアイコン「投資と利益」を開きます。
  2. 比較する方法と期間（例：12週間）を選びます。
  3. 金銭の初回収入・継続収入、時間として得た初回・継続の収入を入力します。
  4. 品質・安全性・成果を比較できる条件を確認して、「収入・成果を保存して計算」を押します。
  5. 費用・作業時間は方法と行動に登録した値から集計されます。

金銭の純利益 ＝ 金銭収入 − 初期費用 − 継続費用

時間の純利益 ＝ 得られる時間 − 準備時間 − 継続作業時間

時間の価値を「円／時」で任意に設定できます。ただし、換算額は実際の現金収入ではありません。

すでに費用の削減に反映した効果を「収入」にも入れると、二重計上になります。未測定なら空欄にしておきます。

08　AI分析とクラウド同期

AIから改善案をもらう

「AI行動分析」から対象の目的・方法を選び、「AIで改善案を分析」を押します。AIの提案は仮説です。削減可能な時間や収益が自動で確定するわけではありません。

PCとiPhoneで同じ記録を使う

  1. 「クラウド同期」を開いてメールアドレスとパスワードで登録します。届いた確認メールのリンクを開きます。登録済みならログインします。
  2. 最初は同期方向を選びます。「この端末 → クラウド」はアップロード、「クラウド → この端末」はダウンロードです。
  3. 初回の同期後は変更が自動送信される設計です。同時編集や上書きに注意します。
ログイン前のゲスト記録とアカウント記録は別です。必要なら「ゲストで作成した記録を取り込む」を使います。同期前にバックアップを保存してください。

09　実際の時間を測る・道具を配置する

実測して改善を確かめる

  1. 「改善の記録」を開き、対象の方法を選びます。
  2. 「計測開始」を押し、準備から後片付けまで計測します。休憩などは一時停止します。
  3. 改善前と改善後の同じ作業量の記録を比べ、検証履歴に残します。

道具の定位置を考える

  1. 「道具・定位置」から道具を登録します。
  2. 使う方法・行動と道具を関連付けます。
  3. 作業の順番に合わせて配置を見直します。

物を置くことが目的ではありません。実際の作業を観察してから必要な道具と定位置を決めます。

10　バックアップとデータ保護

  1. 右側のデータベース形アイコンから「データ管理」を選びます。
  2. 「JSONを書き出す」を押して端末に保存します。
  3. 復元するときは「JSONを読み込む」でファイルを指定します。現在の記録を置き換えるため差分を確認してください。
「初期化」は記録を消す操作です。試す前に必ずバックアップを保存してください。

11　困ったときの早見表

行動を話して記録したい行動を分析 → 音声・文章で記録
片付けや管理も追加したい行動カード → 編集
道具の位置を決めたい道具・定位置 → 道具を登録
改善案と比較したい方法を複製 → 方法を比較
待ち時間を活用したい待ち時間を活かす → 計算して保存
購入品の投資効果を知りたい投資と利益 → 収入・成果を保存して計算
改善前後の時間を測りたい改善の記録 → 計測開始
AIを使いたいクラウド同期でログイン → AI行動分析
PCの記録がiPhoneにない初回同期方向が正しいか確認
画面が古いSafariでページを再読み込み
大切な順番：記録 → 測定 → 比較 → 改善 → 再測定。単なるコスト削減だけでなく、行動が生む時間とお金の純利益を考えます。
